# Arcmedian site

Static site for Arcmedian — a measurement-integrity and marketing-intelligence
practice — hosted on GitHub Pages at `https://arcmedian.co.uk/`.

## Pages

- `index.html` — landing page: positioning, method, worked-example teaser, founder
- `case-study.html` — full worked analysis (the portfolio centrepiece)

## Supporting files

- `styles.css` — visual design and responsive layout
- `script.js` — reveal-on-scroll, scroll meter, footer year
- `case-study/` — the real analysis behind the case study
  - `notebook/measurement_integrity_audit.py` — the full Python analysis
  - `charts/` — generated SVG/PNG charts (brand palette)
  - `findings.json` — every headline figure, computed from source
  - `data/README.md` — how to fetch the dataset and reproduce
- `cv/` — downloadable CV (PDF)
- `assets/`, `brand-kit/` — logo system and brand assets
- `robots.txt`, `sitemap.xml`, `CNAME` — hosting/SEO

## Reproduce the analysis

```bash
# 1. fetch the dataset (see case-study/data/README.md)
# 2. from the project root:
python3 case-study/notebook/measurement_integrity_audit.py
```

Every number on the case-study page is generated by that script from the public
UCI Online Retail II dataset. Nothing is hand-entered.
